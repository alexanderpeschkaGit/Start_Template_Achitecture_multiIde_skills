<#
.SYNOPSIS
    Bootstraps the Progressive-Disclosure AI Agent Architecture (AGENTS.md + .agents/rules + .agents/skills + IDE adapters) into a new or existing project directory.

.DESCRIPTION
    Generates a clean, project-agnostic 3-layer agentic governance scaffold:
    - Layer 0: Thin IDE adapters (GEMINI.md, .clinerules, .cursor/rules/agents.mdc)
    - Layer 1: Root router (AGENTS.md) with Deterministic File-to-Rule Routing
    - Layer 2: Lazy-loaded domain rules (.agents/rules/*.md with trigger: model_decision)
               and on-demand workflow skills (.agents/WORKFLOWS.md + .agents/skills/*/SKILL.md)

.PARAMETER TargetDir
    Destination project root directory.

.PARAMETER ProjectName
    Human-readable project name used in comments/headers (default: "MyProject").

.PARAMETER Force
    Overwrite existing files in TargetDir if present.

.PARAMETER DryRun
    Preview the files that would be created without writing to disk.

.EXAMPLE
    powershell -ExecutionPolicy Bypass -File scripts/patches_and_tests/init-agent-architecture.ps1 -TargetDir "C:\Projects\NewApp" -ProjectName "NewApp"
#>

[CmdletBinding()]

    [switch]$Force,

    [switch]$DryRun

$ErrorActionPreference = "Stop"

function Write-ScaffoldFile {
    param(
        [string]$RelativePath,
        [string]$Content
    )
    $FullPath = Join-Path -Path $TargetDir -ChildPath $RelativePath
    $ParentDir = Split-Path -Path $FullPath -Parent

    if ($DryRun) {
        Write-Host "[DRY-RUN] Would create: $RelativePath" -ForegroundColor Cyan
        return
    }

    if (-not (Test-Path -LiteralPath $ParentDir)) {
        New-Item -ItemType Directory -Path $ParentDir -Force | Out-Null
    }

    if ((Test-Path -LiteralPath $FullPath) -and (-not $Force)) {
        Write-Host "[SKIP] Exists (use -Force to overwrite): $RelativePath" -ForegroundColor Yellow
        return
    }

    $Utf8NoBom = New-Object System.Text.UTF8Encoding($false)
    [System.IO.File]::WriteAllText($FullPath, $Content, $Utf8NoBom)
    Write-Host "[OK] Created: $RelativePath" -ForegroundColor Green
}

$RuleMultiIde = @"
---

description: "Apply this when configuring IDE adapters, routing workflow commands, or delegating tiered subagents across multi-IDE environments."
---

# Shared Instructions, IDE Adapters & Execution Contract (SSOT)

This file is the **Single Source of Truth** for multi-IDE routing, the 3-tier model complexity matrix, and subagent verification. Workflow skills in ``.agents/skills/`` reference this file rather than duplicating these tables.

## 1. Progressive Disclosure Routing Tree

``[IDE Dotfile]`` ──points to──> ``AGENTS.md`` ──delegates on demand to──> ``[.agents/rules/*.md & .agents/WORKFLOWS.md]``

1. **IDE adapters (``GEMINI.md``, ``.clinerules``, ``.cursor/rules/agents.mdc``):** Point to ``AGENTS.md`` without duplicating project policy.
2. **``AGENTS.md`` (Root):** Loaded every turn. Holds global invariants and the file-to-rule routing table.
3. **``.agents/rules/*.md``:** Loaded dynamically on demand based on the files being modified. Every rule file MUST start with YAML frontmatter using ``trigger: model_decision``, ``globs``, and ``description``.
4. **``.agents/WORKFLOWS.md``:** Maps ``#tags`` / ``/commands`` to ``.agents/skills/<name>/SKILL.md``.

## 2. Unified 3-Tier Model Routing (``#plan``, ``#exec``, ``#delegate``, ``#solve``)

| Tier | Complexity Score | Target Scope | Subagent Model (Mode A) |
| :--- | :--- | :--- | :--- |
| **Tier 1 (``FLASH_LITE``)** | ``1–3`` | Copy updates, simple type exports, config tweaks, minor CSS/Tailwind (<300 lines) | ``flash_lite`` |
| **Tier 2 (``FLASH``)** | ``4–6`` | Standard component/hook batches (<= 3–4 files, clear interfaces, <500 lines) | ``flash`` *(Default)* |
| **Tier 3 (``PRO``)** | ``7–10`` | Cross-file Zustand state, SSR/Hydration, complex lifecycles, files >=500 lines | ``pro`` *(+ Reviewer at >=8)* |

- **Auto-Escalation Rule:** If a Tier 1 or Tier 2 step fails validation (``npm run lint`` / ``npm test``) and survives **one** diagnostic repair attempt, escalate that step to Tier 3 (``pro``).

## 3. Combo Anti-Phantom Diff Audit

After every subagent return or implementation batch, run both probes and reconcile their union against the planned File Inventory:

````powershell
git --no-pager diff --name-only
git --no-pager status --porcelain
````

If an assigned file is missing from the union, reject the subagent's report as ``INCOMPLETE_TASK`` and complete the missing edits before staging.

## 4. Acceptance & Audit Criteria

1. All IDE adapter files point strictly to ``AGENTS.md``.
2. Every file in ``.agents/rules/*.md`` begins with valid ``trigger: model_decision`` YAML frontmatter.
3. Living cross-IDE execution plans and handoff reports write to ``.tmp/`` (gitignored).
"@

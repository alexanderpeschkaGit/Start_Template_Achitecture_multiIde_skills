# Architecture Interview Skill (`#grillme`)

1. **No Premature Coding:** Do NOT modify code during `#grillme`.
2. **Inspect First:** If a question can be answered by reading the repository, read the relevant files yourself instead of asking the user.
3. **One Question at a Time:** Walk down the design tree (scope, state ownership, edge cases, failure paths) asking focused, high-leverage questions until all ambiguities are resolved.
